# shardrop.com

Static site for Shardrop, served by GitHub Pages.

- `/` home page
- `/d/?n=<daily>&s=<score>` daily challenge page that shared results link to
- `/.well-known/apple-app-site-association` lets challenge links open the app (team Z2H89V93X7, `com.lokesh.shardrop`)
- `/app-ads.txt` authorizes Google AdMob (publisher `pub-2408635475422098`)
- `/d/og.png` link preview image
